Im Chat steht jetzt vor jedem Repo das Favicon der App, so wie es auf `main` liegt. Das gilt für die Liste links, für die Auswahl auf dem Handy und für das gerade gewählte Repo. Hat ein Repo keins, erscheint ein graues Feld mit dem Anfangsbuchstaben. Ein geändertes Favicon zeigt der Chat spätestens am nächsten Tag. Auf dem Handy sieht die Repo-Auswahl jetzt etwas anders aus, sie ist eine eigene Liste statt des Systemmenüs.
